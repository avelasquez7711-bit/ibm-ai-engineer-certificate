# Module 5: Building Convolutional Neural Networks
The folder contains the hands-on labs for Module 5 of [Deep Learning with PyTorch](../../05-deep-learning-with-pytorch/) course.

## [Lab 1: What's Convolution](./What_is_Convolution.ipynb) Objectives

After completing this lab, you will be able to:
- Describe what is convolution.
- Determine the size of an output. 
- Use stride and zero padding.

## [Lab 2: Activation Function and Max Pooling](./Activation_max_pooling.ipynb) Objectives

After completing this lab, you will be able to:
- Apply an activation function.
- Use max pooling.

## [Lab 3: Multiple Input and Output Channels](./Multiple_Channel_Convolution.ipynb) Objectives

After completing this lab, you will be able to:
- Describe how convolutional layers use multiple output channels to produce multiple activation maps.
- Explain how kernels are applied across multiple input channels in a convolutional neural network.
- Configure PyTorch `Conv2d` layers with multiple input and output channels.
- Interpret convolution outputs by comparing tensor shapes, channel outputs, kernels, and activation maps.  

## [Lab 4: Convolutional Neural Network Simple Example](./ConvolutionalNeralNetworkSimple_example.ipynb) Objectives

After completing this lab, you will be able to:
- Use a convolutional neural network to classify horizontal and vertical lines 
- Apply helper functions
- Prepare data
- Build a convolutional neural network class
- Define the convolutional neural network classifier, criterion function, optimizer and train the model

## [Lab 5: Convolutional Neural Network MNIST](./CNN_Small_Image.ipynb) Objectives

After completing this lab, you will be able to:
- Use a Convolutional Neural Network to classify handwritten digits from the MNIST database
- Reshape the images for faster processing

## [Lab 6: Convolutional Neural Networks with Batch Normalization](./CNN_Small_Image_batch.ipynb) Objectives

After completing this lab, you will be able to:
- Learn how to compare a Convolutional Neural Network using Batch Normalization with a regular Convolutional Neural Network to classify handwritten digits from the MNIST database.
