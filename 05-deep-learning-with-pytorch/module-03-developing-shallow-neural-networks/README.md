# Module 3: Developing Shallow Neural Networks
The folder contains the hands-on labs for Module 3 of [Deep Learning with PyTorch](../../05-deep-learning-with-pytorch/) course.

## [Lab 1: Neural Networks in One Dimension](./simple1hiddenlayer.ipynb) Objectives

After completing this lab, you will be able to:
- Create a simple neural network in PyTorch

## [Lab 2: Neural Network with Different Activation Functions](./mist1layer_v2.ipynb) Objectives

After completing this lab, you will be able to:
- Apply different activation functions on the MNIST dataset 

## [Lab 3: More Hidden Neurons](./multiple_neurons.ipynb) Objectives

After completing this lab, you will be able to:
- Create complex Neural Network in PyTorch 

## [Lab 4: Multidimensional Neural Network](./xor_v2.ipynb) Objectives

After completing this lab, you will be able to:
- Create a neural network model with multiple neurons 

## [Lab 5: Multi-Class Neural Networks with MNIST](./one_layer_neural_network_MNIST.ipynb) Objectives

After completing this lab, you will be able to:
- Classify handwritten digits using Neural Network
