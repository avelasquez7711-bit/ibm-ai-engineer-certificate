# Module 4: Optimizing Deep Networks
The folder contains the hands-on labs for Module 4 of [Deep Learning with PyTorch](../../05-deep-learning-with-pytorch/) course.

## [Lab 1: Deep Neural Networks](./mist2layer_v2.ipynb) Objectives

After completing this lab, you will be able to:
- Define Neural Network, Criterion Function, and Optimizer
- Test Sigmoid, Tanh and ReLU
- Analyze Results

After completing this lab, you will be able to:

- Train and Validate the Model
