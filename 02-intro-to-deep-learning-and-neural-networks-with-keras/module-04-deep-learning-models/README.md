# Module 4: Deep Learning Models
The folder contains the hands-on labs for Module 4 of [Introduction to Deep Learning & Neural Networks with Keras](../../02-intro-to-deep-learning-and-neural-networks-with-keras/) course.

## [Lab 1: Convolutional Neural Networks with Keras](./Convolutional-Neural-Networks-with-Keras.ipynb) Objectives

After completing this lab, you will be able to:

* How to use the Keras library to build convolutional neural networks
* Convolutional neural network with one set of convolutional and pooling layers
* Convolutional neural network with two sets of convolutional and pooling layers

## [Lab 2: Transformers with Keras](./Transformers-with-Keras.ipynb) Objectives
