# Module 3: Building Supervised Learning Models
The folder contains the hands-on labs for Module 3 of [Machine Learning with Python](../../01-machine-learning-with-python) course.

## [Lab 1: Multi-class Classification](./Multi-class_Classification.ipynb) Objectives

After completing this lab you will be able to:

* Understand the use of one-hot encoding for categorical variables.
* Implement logistic regression for multi-class classification using **One-vs-All (OvA)** and **One-vs-One (OvO)** strategies.
* Evaluate model performance using appropriate metrics.

## [Lab 2: Decision Trees](./Decision_trees.ipynb) Objectives

After completing this lab you will be able to:

* Develop a classification model using Decision Tree Algorithm
* Apply Decision Tree classification on a real world dataset.

## [Lab 3: Regression Trees](./Regression_Trees_Taxi_Tip.ipynb) Objectives

After completing this lab you will be able to:

* Perform basic data preprocessing using Scikit-Learn
* Model a regression task using Scikit-Learn
* Train a Decision Tree Regressor model
* Run inference and assess the quality of the trained models

## [Lab 4: Fraud Detection w/ Decision Trees + SVM](./decision_tree_svm_ccFraud.ipynb) Objectives

After completing this lab you will be able to:

* Perform basic data preprocessing in Python
* Model a classification task using the Scikit-Learn Python APIs
* Train Suppport Vector Machine and Decision Tree models using Scikit-Learn
* Run inference and assess the quality of the trained models

## [Lab 5: K-Nearest Neighbors Classifier](./KNN_Classification.ipynb) Objectives

After completing this lab you will be able to:

*   Use K-Nearest neighbors to classify data
*   Apply KNN classifier on a real world data set 

## [Lab 6: Random Forest + XGBoost](./Random_Forests_XGBoost.ipynb) Objectives

After completing this lab you will be able to:

* Use scikit-learn to implement Random Forest and XGBoost regression models
* Compare the performances of the two models
