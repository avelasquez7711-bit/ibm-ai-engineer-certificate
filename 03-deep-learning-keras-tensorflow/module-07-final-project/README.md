# Module 7: Final Project
The folder contains the hands-on labs for Module 7 of [Deep Learning with Keras and Tensorflow](../../03-deep-learning-keras-tensorflow/) course.

## [Practice Project: Fruit Classification Using Transfer Learning](./Practice_Project_Fruit_Classification_Using_TF.ipynb) Objectives

After completing this lab, you will be able to:
- Set up and organize a complex fruit image dataset.
- Use transfer learning with the VGG16 model.
- Fine-tune a pre-trained model for your dataset.
- Evaluate and interpret the model’s performance on unseen data.

## [Final Project: Classify Waste Products Using Transfer Learning](./Final_Proj-Classify_Waste_Products_Using_TL_FT.ipynb) Objectives

After completing this lab, you will be able to:
- Apply transfer learning using the VGG16 model for image classification.
- Prepare and preprocess image data for a machine learning task.
- Fine-tune a pre-trained model to improve classification accuracy.
- Evaluate the model’s performance using appropriate metrics.
- Visualize model predictions on test data.
