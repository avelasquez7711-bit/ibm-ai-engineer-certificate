# Module 6: Introduction to Reinforcement Learning with Keras
The folder contains the hands-on labs for Module 5 of [Deep Learning with Keras and Tensorflow](../../03-deep-learning-keras-tensorflow/) course.

## [Lab 1: Implementing Q-Learning in Keras](./Implementing_Q-Learning_in_Keras.ipynb) Objectives

After completing this lab, you will be able to:
- Implement a Q-Learning algorithm using Keras
- Define and train a neural network to approximate the Q-values
- Evaluate the performance of the trained Q-Learning agent

## [Lab 2: Building a Deep Q-Network with Kera](./Building_a_Deep_Q-Network_with_Keras.ipynb) Objectives

After completing this lab, you will be able to:
- Implement a Deep Q-Network using Keras  
- Define and train a neural network to approximate the Q-values  
- Evaluate the performance of the trained DQN agent
