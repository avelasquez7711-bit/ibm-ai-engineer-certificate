# Module 1: Advanced Keras Functionalities
The folder contains the hands-on labs for Module 1 of [Deep Learning with Keras and Tensorflow](../../03-deep-learning-keras-tensorflow/) course.

## [Lab 1: Implementing the Functional API in Keras](./Implementing_Functional_API_Keras.ipynb) Objectives

After completing this lab, you will be able to:
- Use the Keras Functional API to build a simple neural network model. 
- Create an input layer, add hidden layers, and define an output layer using the Functional API. 

## [Lab 2: Creating Custom Layers and Models](./Creating_Custom_Layers_and_Models.ipynb) Objectives

After completing this lab, you will be able to:
- Create custom layers and integrate them into a Keras model 
- Compile, train, and evaluate the model
