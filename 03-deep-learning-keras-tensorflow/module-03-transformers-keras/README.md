# Module 3: Transformers in Keras
The folder contains the hands-on labs for Module 3 of [Deep Learning with Keras and Tensorflow](../../03-deep-learning-keras-tensorflow/) course.

## [Lab 1: Building Advanced Transformers](./Building_Advanced_Transformers.ipynb) Objectives

After completing this lab, you will be able to:
- Understand the core components of a Transformer architecture.
- Implement a multi-head self-attention mechanism from scratch.
- Train and evaluate a Transformer for time series prediction.
- Handle preprocessing and scaling for time series data effectively.
