# Module 2: Advanced CNNs with Keras
The folder contains the hands-on labs for Module 2 of [Deep Learning with Keras and Tensorflow](../../03-deep-learning-keras-tensorflow/) course.

## [Lab 1: Advanced Data Augmentation with Keras](./Advanced_Data_Augmentation_Keras.ipynb) Objectives

After completing this lab, you will be able to:
- Implement various data augmentation techniques using Keras 
- Implement feature-wise and sample-wise normalization on the data set. 
- Define and apply a custom augmentation function that adds random noise to images. 
- Display the augmented images to understand the effect of different augmentation techniques.  

## [Lab 2: Transfer Learning Implementation](./Transfer_Learning_Implementation.ipynb) Objectives

After completing this lab, you will be able to:
- Import necessary libraries and load the dataset.
- Load a pre-trained model, VGG16, excluding the top layers.
- Add new layers on top of the base model and compile the model.
- Train the model on the new dataset.
- Unfreeze some of the layers of the pre-trained model and fine-tune them.

## [Lab 3: Practical Application of Transpose Convolution](./Practical_Application_Transpose_Convolution.ipynb) Objectives

After completing this lab, you will be able to:
- Apply transpose convolution in practical scenarios using Keras.  
- Create, compile, train, and evaluate the model 
- Visualize the results
