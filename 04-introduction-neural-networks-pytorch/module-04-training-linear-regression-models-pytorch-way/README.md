After completing this lab, you will be able to:
- Use SGD (Stochastic Gradient Descent) to train the model.
- Use the Data Loader module.

## [Lab 2: Mini-Batch Gradient Descent](./mini-batch_gradient_descent_v3.ipynb) Objectives

After completing this lab, you will be able to:
- Use Mini-Batch Gradient Descent to train model.

## [Lab 3: Optimization in PyTorch](./PyTorchway_v3.ipynb) Objectives

After completing this lab, you will be able to:

After completing this lab, you will be able to:
